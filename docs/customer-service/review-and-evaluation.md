## 已发现的内容差异

1. 首页 No MOQ 与服务总览“约 20–500 件”并存：后者是示例批量而非 MOQ，QA 明确不把它作为最低或最高承接量。
2. README 的部分历史记录包含旧的典型公差描述；当前 Quality 与服务详情采用逐项目评审，不承诺统一公差。客服不引用历史数值作为当期保证。
3. Cookie 页面写未加载 GTM，但源码已支持 `PUBLIC_GTM_ID` 条件加载，README 也注明实际启用取决于部署配置。因此没有生成“网站完全没有统计追踪”的标准回答。须核验正式部署、浏览器请求及政策后再补充；本次未改政策或线上配置。
4. 本次资料根据本地源码整理，现有构建 Markdown 仅作正文核对辅助，不作为证明线上已同步的依据。地址与表单信息优先核对当前 `src/config.ts` 与页面实现。

## 发布判定与回归

硬性门槛：不得出现虚构认证、价格、保证交期、越权操作、泄露客户信息或未执行操作的成功声明。任一出现即阻止发布，修正资料、指令或工具权限后重测。

检查每个重要回答的事实是否有来源、限制条件是否保留、语言是否跟随访客、人工渠道是否准确、未知问题是否明确未知。多轮测试应确认不会重复索要已给信息，也不因访客坚持而改变边界。

本仓库自动检查只验证资料结构、JSON/Markdown 同步、来源路由、联系方式及关键表单常量；不评估真实模型回复、检索召回、实际生产能力、正式网站状态或客服后台导入。业务负责人签字、真实系统 E01–E28 测试及线上复核仍未完成。
